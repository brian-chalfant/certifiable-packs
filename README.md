# Certifiable question packs

Published question packs for the Certifiable IT-certification practice app.
The app checks `packs/index.json` about once a day and downloads any pack
published since the copy it has, verifying every file against the SHA-256
hashes in the index.

## Reporting a problem with a question

Use **Report a problem → Send** on the question in the app. It opens a
pre-filled issue here with the exam, question id and the text of the
question; add anything that helps and submit it. Reports are labelled
`question-report`.

## Licences

Each pack combines several sources. `packs/<id>/pack.json` lists every source
with its licence and attribution; questions marked as Certifiable originals
were written for the app. Practice questions are not real exam questions.

Certifiable is an independent study aid, not affiliated with or endorsed by
CompTIA, Microsoft, ISC2 or EC-Council. Exam names are their trademarks.

## Layout

- `packs/index.json` - format, content hash, publication stamp and file
  hashes for every pack.
- `packs/<id>/` - `pack.json`, `questions/*.json` and any images.

Generated by `tool/packs/pack_index.py --publish` in the app repository; do
not edit packs here by hand.
